# Meet the Squad

This repository uses a descriptive Squad cast. Squad coordinates work; the
specialists below own implementation domains.

| Specialist | Focus |
|------------|-------|
| `architect` | Cross-package architecture, compatibility strategy, adjudication |
| `agent-orchestration-dev` | Coordinator, casting, routing, prompts, spawns, handoffs |
| `typescript-api-contract-designer` | Public TypeScript APIs, exports, schemas, declarations |
| `sdk-runtime-dev` | SDK clients, sessions, events, streams, tools, cancellation, concurrency |
| `plugin-platform-dev` | Plugins, marketplaces, manifests, sharing, upstreams, adapters |
| `cli-dev` | CLI commands, parsing, init, upgrade, migrations, templates |
| `terminal-ux-dev` | Ink and REPL interaction, rendering, input, focus, accessibility |
| `state-storage-dev` | State backends, memory, serialization, migrations, recovery |
| `git-specialist` | Local Git, refs, worktrees, staging, merges, repository recovery |
| `github-integration-dev` | GitHub APIs, CLI, auth, issues, labels, PRs |
| `agentic-workflows-dev` | gh-aw compilation, permissions, safe outputs, contracts |
| `observability-dev` | OpenTelemetry, logs, metrics, traces, health, cost visibility |
| `dotnet-agent-framework-dev` | Squad.Agents.AI, .NET integration, NuGet contracts |
| `unit-contract-tester` | Vitest, deterministic unit and contract validation |
| `integration-e2e-tester` | CLI, Gherkin, Playwright, hosted workflow lifecycle evidence |
| `security-reviewer` | Threat models, trust boundaries, secrets, injection, filesystem review |
| `release-engineer` | Builds, manifests, changesets, CI, package publication |
| `docs-devrel` | README, guides, examples, migrations, API docs, website |

## Built-in Support

- **Scribe** — durable decision merging
- **Ralph** — work queue monitoring
- **Rai** — responsible-AI review
- **Fact Checker** — claim verification and devil's-advocate analysis

Support identities are not specialist registry entries or dispatch targets.
`@copilot` remains the general coding agent.
