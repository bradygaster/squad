Quality-profile and public-catalog aware model selection (#1598). Task-aware selection now runs under a quality profile: `quality-first` (the new default), `balanced` or `economy` (explicit opt-in). Under `quality-first`, architecture, research, verification, review, security, design and visual work use the premium tier; code, prompts, docs, writing and planning use standard; mechanical work (Scribe, git, release) stays fast. The `default` layer now uses the head of the standard chain, or the economy default under `economy`. The profile comes from a session profile (`sessionProfile`), `economyMode: true`, or the persistent `.squad/config.json` `modelProfile` (new `readModelProfile` / `writeModelProfile`, `isModelSelectionProfile`, `MODEL_SELECTION_PROFILES`, `PROFILE_TASK_TIERS`, `resolveModelProfile`). `ResolvedModel.profile`, rationales, the `model.profile` span attribute and the `model.resolved` event report the active profile. Profiles never change explicit user-override, config, session or charter models, and cost ceilings still apply. `economyMode` stays compatible: an explicit `economyMode: false` cancels a persisted `economy` profile. `readEconomyMode` (and `squad economy`) also reports enabled for `modelProfile: "economy"`, and `writeEconomyMode(dir, false)` (`squad economy off`) also removes a persisted `economy` profile, leaving other profiles unchanged.

`resolveAgentModel` and `AgentLifecycleManager.spawnAgent` accept `availableModels`, the runtime's live model list. When supplied, it is authoritative for availability: a missing recommended model falls forward through its chain, and a missing explicit model falls back visibly.

The model catalog, fallback chains (`MODELS.FALLBACK_CHAINS`, `DEFAULT_FALLBACK_CHAINS`, `DEFAULT_CONFIG.models.tiers`) and `ECONOMY_MODEL_MAP` now list only public GA models from the GitHub Copilot supported-models table, with tiers placed by the Copilot model-picker category. Added: `claude-opus-5.5`, `gpt-6.1-sol`, `gpt-6-sol`, `gemini-4-argon`, `claude-sonnet-5.5`, `grok-4.7`, `grok-4.6`, `claude-haiku-5.5`, `gpt-6-luna`, `gemini-3.8-flash`, `mai-code-1.1-flash`. Removed from recommendations, catalog and fallback chains: `claude-opus-4.7`, `claude-opus-4.6`, `claude-sonnet-4.6`, `claude-sonnet-4.5`, `gemini-3.1-pro`. These IDs are still passed through unchanged when a user names one explicitly.
